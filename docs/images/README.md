# 实机截图来源

- 设备：Redmi K90 Pro Max，Android 16；应用版本 Q-screenshot 0.7.1。
- 日期：2026-10-31。
- 获取方式：通过已授权 ADB 的 `exec-out screencap -p` 直接捕获系统合成的应用屏幕。拍摄前核对前台为本应用 `dev.qingframe/.MainActivity`。
- 两张 PNG 均保持原始 1200×2608 像素，未裁剪、调色或重绘。README 仅控制显示宽度。
- 使用独立示例工程和应用内原创离线示例图片；没有访问私人图库或通知内容，没有使用模拟器截图或把渲染导出 PNG 当作实机界面。

| 文件 | 展示内容 |
|---|---|
| `redmi-editor.png` | 实机编辑 REDMI K90 Pro Max 主屏模型 |
| `fold-editor.png` | 同一实机编辑 Xiaomi 18 Fold 外屏、西野红模型 |

第二张不是 Xiaomi 18 Fold 实机系统屏幕，而是 Q-screenshot 在 Redmi 上显示该模型的编辑界面。
